Features

Built for people who just want to play

Powerful when you need it, simple when you don't. Here's everything that comes with every Tree Host server.

Any type, any version

Paper, Fabric, Vanilla and more, on any version

Pick the server software and the Minecraft version you want: from 1.8 to the newest release, and snapshots too. Tree Host downloads it and the right Java version for you.

  • Paper, Purpur, Folia, Spigot, CraftBukkit
  • Fabric for mods, Vanilla for the pure game
  • Velocity, Waterfall and BungeeCord proxies
  • Switch version any time; your world is kept
Plugins & mods

Install plugins in one click

Search thousands of plugins and mods from Modrinth without leaving the dashboard. Tree Host only shows the ones that work on your server's type and version, and checks every download.

  • LuckPerms, WorldEdit, EssentialsX and more
  • Drag and drop your own jars
  • Enable, disable or remove with one click
Live console

Your server, live

See every log line the moment it happens, run commands, and fix problems fast with errors highlighted in red.

  • Quick buttons: OP me, whitelist me, day, weather, TPS
  • Memory and disk use shown live
  • Restarts by itself after a crash
Backups

Never lose your world

Make a backup with one click before a big change, or let Tree Host back up automatically every 6 hours, 12 hours or once a day. Restoring is one click too.

  • Worlds, nether, end and plugin data
  • Works while the server is running
  • Named backups you can find later

And everything else

File manager

Edit server.properties, plugin configs and any text file in your browser.

Game settings

Difficulty, game mode, whitelist, view distance, seed and more, without editing files.

Isolated servers

Every server runs on its own, walled off from the others, with its own memory, CPU and disk.

For plugin developers

Upload builds straight from Gradle or Maven with an API token. The server restarts with your new jar.

Activity log

See every start, stop, install and backup on your servers, with times.

Simple billing

Pay monthly by card through a secure checkout. Change your card or cancel from your dashboard.
