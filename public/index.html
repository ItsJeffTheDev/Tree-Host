FAQ

Questions

How fast is my server ready?

About a minute after you pay: pick the type and version, and Tree Host downloads and starts it for you.

Which server types are supported?

Paper, Purpur, Folia, Spigot, CraftBukkit, Fabric, Vanilla, and the Velocity, Waterfall and BungeeCord proxies, on any version they released. Forge and NeoForge are not supported yet.

Can I install my own plugins and mods?

Yes. Install from the built-in browser, drag and drop your own jars, or edit any file in the file manager.

How do I cancel?

In your dashboard: Billing → Payment method & invoices. Your server stays until the end of the period you paid for.
