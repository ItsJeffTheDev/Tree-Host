The model

Why sleep-when-empty means structurally lower prices

A 24/7 host must charge enough that busy-hour memory covers the whole machine. A host whose servers sleep sells the same memory several times over — the math below uses Tree Host's real plan prices.

Competitor range: regular monthly prices for the same memory from Shockbyte, Apex Hosting and Sparked Host (public pricing pages, checked October 2026 — the Why page shows the live comparison and its sources).

Sleep, don't idle. An empty Tree Host server uses no memory and no CPU; the port keeps answering and the server wakes when a player joins (~30 seconds).

Sell the same RAM more than once. Player populations overlap only partially — servers are empty much of the day and night. Oversubscribing sleeping capacity is how one machine serves many more customers than a 24/7 host can.

Lower prices are structural, not promotional. Competitors discount the first month to win signups; our price holds because the cost base is genuinely smaller. Every plan also includes unlimited servers, backups, and every feature — no tier games.

One-time revenue up front. Lifetime ($950) and the $199 Founding pre-sale fund hardware before launch, so growth doesn't wait on outside capital.

One launch machine (Ryzen 7 9700X, 64 GB) has ~58 GB usable. At Sapling's 2 GB + overhead that's roughly 24 concurrent Sapling customers ≈ $120/mo per machine — before any sleep-based oversubscription, which is where the margin actually comes from.
Product moat

Things players can't get elsewhere

Price gets a signup; these keep a customer — and each one makes the next customer cheaper to win.

Crash doctor

When a plugin crashes the server, Tree Host restarts it by itself and explains the error in plain words — the support ticket that never needs writing.

Lag doctor

Checks a running server's TPS, tick times and entities on demand, then names the likely cause. Players feel lag before they can describe it; the doctor closes that gap.

Verified staff badges

Tree Host staff wear a gold STAFF badge in chat that can't be faked, so players learn to trust the name on every server we host.

Built-in server list flywheel

Every customer can list their server publicly. Each server advertised to its players is a free Tree Host billboard — customer acquisition built into the product.

Modrinth integration

One-click plugins, mods and full Fabric modpacks, with versions checked against the server's type before install. The catalog maintenance competitors do by hand is automatic here.

Built for the long tail

Unlimited servers per plan, Bedrock crossplay in one click, and a Lifetime option no monthly-only competitor matches — players stay because leaving costs them their setup.
