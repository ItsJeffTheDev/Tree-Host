Before you go live
  • Turn on Streamer mode in the dashboard (account menu, or Ctrl+Shift+S): emails and IP addresses are hidden.
  • The tester link changes when Start-Testers restarts. The overlays always show the current one; refresh the browser sources in OBS if needed.
  • A shorter link on screen: add ?link=your.short.link to the bar or screen URL (it's shown and put in the QR code instead).
  • playit's free plan has only a few public addresses: servers past that wait for one (they never show your IP).
